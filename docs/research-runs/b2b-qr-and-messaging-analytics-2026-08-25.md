## Исходный запрос (как гипотеза)

> Дать организации собственный QR без персонального реферера, применить её приветственную скидку и показать полную статистику рассылок Telegram/MAX.

- Скрытое допущение: ссылка только с `utm_org` достаточно надёжно привяжет нового клиента к организации, а API мессенджеров позволит узнать персональное прочтение.
- Почему выбран этот инструмент: задача затрагивает регистрацию, multi-org членство, скидку первой покупки, доставку сообщений и трактовку продуктовых метрик.

## Гипотезы

### H1

- level: process
- action: Создавать membership при регистрации с utm_org без персонального реферера.
- mechanism: Разрешённая активная организация записывается в User и PartnerOrganizationMembership до начислений.
- metric: Доля org-only регистраций, присутствующих в membership целевой организации.
- baseline: Регистрация могла иметь только legacy organizationId.
- target: Каждая успешная org-only регистрация имеет membership той же организации.
- deadline: 2026-08-25
- source_contexts: C1, C3, C4
- cheap_test: Unit test UserService с utm_org и без utm_ref.
- success_criterion: Membership upsert вызван с разрешённой организацией.
- falsification_criterion: Пользователь создан, но membership отсутствует или создан до approval.
- confidence: high

### H2

- level: interface
- action: Убрать фиктивный Open Rate и включить реальную доставку MAX с click tracking.
- mechanism: UI и API показывают только SENT, FAILED, unique clicked, total clicks и CTR.
- metric: Отсутствие новых opened/read записей и корректный unique clicked после повторных кликов.
- baseline: MAX не отправлялся, а click увеличивал openedCount.
- target: MAX проходит очередь, первый click увеличивает unique, повторный только total clicks.
- deadline: 2026-08-25
- source_contexts: C1, C4, C5, C6, C7, C8
- cheap_test: Unit tests tracker и analytics plus targeted build.
- success_criterion: API не возвращает Open Rate, а чужой recipient не записывает клик.
- falsification_criterion: Клик меняет openedAt или mailingId можно пересечь чужим recipientId.
- confidence: high
